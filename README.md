# Expense Tracker

## Overview
This project is a simple Java-based expense tracker designed to help users monitor incoming and outgoing money, review their transaction history, and keep track of their remaining balance. It is built as a console application with a clean separation between the data model, business logic, and user interface.

## Features
- Add income and expense transactions
- View all recorded transactions
- Remove transactions by ID
- See total income, total expenses, and current balance
- Use a beginner-friendly command-line menu
- Keep the project lightweight with no external dependencies

## [Technology Stack](https://github.com/KingVics/GUI_expenseTracker#technology-stack)
- Java
- Standard Java library (`Scanner`, collections, enums)
- Console-based user interface

## Usage
1. Open a terminal in the project root.
2. Compile the project:

   ```bash
   javac Main.java
   ```

3. Run the app:

   ```bash
   java Main
   ```

4. Use the menu options:
   - 1. Add transaction
   - 2. View transactions
   - 3. Remove transaction
   - 4. View financial summary
   - 5. Exit

### Example
- Select option `1` to add a new income or expense
- Enter the amount, category, and optional description
- Select option `4` to review your financial summary
